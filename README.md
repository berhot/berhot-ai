# Berhot AI

- `jsm_0.1`: Arabic text model, corpus pipeline, training and chat apps.
- `jsm-voice`: Arabic speech recognition, text-model integration and custom TTS.

Start with the [GPU training runbook](docs/GPU_TRAINING.md) to prepare data, export
an offline bundle, install on a rented NVIDIA GPU, run preflight/smoke checks,
resume training and evaluate checkpoints. GPU settings are configurable.

Current model weights are experimental; successful training is not evidence of
production conversation or voice quality.
